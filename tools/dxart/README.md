# 畫中有話卡圖工具（tools/dxart）

`dx/c000.webp`–`c167.webp` 168 張卡面就係用呢度嘅工具整。全部自己畫（GAME-27），唔用人哋嘅圖。

## 點樣整
1. 用 SVG 砌場景：`art6.js` 每個 `S.push` 係一個場景（0–40 香港元素，41 之後夢幻）。
   - `art1.js`：天空、雲、月、海、城市、濾鏡（立體打光、手繪邊）
   - `art2.js`：物件、動物、人物（電車、天星小輪、蛋撻、鯨魚、狐狸……）
   - `art5.js`：環境底（海、維港、草地、森林、雪地、沙漠、雲海、湖、霓虹街、海底、房、宇宙、天台）：前中後景、霧、光、倒影
   - `svg.js`：出一張卡嘅 SVG
2. 出圖、畫油畫、揀卡（要 Node + Playwright、Python 3 + OpenCV）：
   ```
   node render.js raw 900          # 每個場景出一張 PNG（r000.png…）
   python3 paint.py raw painted     # 一筆一筆畫成油畫（c000.webp…，540×810）
   python3 pick.py painted ../../dx # 照 keep.json 揀 168 個場景，抄做 dx/c000.webp…c167.webp
   ```
3. 換咗卡圖：`index.html` 嘅 `DX_IMG_V` 加 1，手機先唔會用舊快取。

## 油畫點樣畫（paint.py）
- 先用大筆掃底，再一層層細筆（筆闊 24 → 2.2）；細筆只落喺同原圖差得遠嘅位（邊、細節）
- 每筆係沿住畫面方向嘅橢圓（結構張量），有少少色差，大筆上面加一條光邊（似顏料厚）
- 最後：亮度對比對返原圖、厚塗光影、畫布紋理、暖色、輕微暗角

## keep.json
第 n 張卡用第幾個場景。190 個場景入面揀咗 168 個，唔要嘅係睇落唔清楚或者似公仔畫嗰啲。改場景之後要再睇一次全部卡先改 keep.json。
